# Chrone

**Chrone** — настольный браузер, созданный для комфортной работы
в интернете. Удобные вкладки, рабочие пространства и настройки
приватности помогают организовать браузер под себя.

> Проект находится в разработке. Некоторые функции могут работать
> нестабильно или измениться в будущих версиях.

## Возможности

### Вкладки и рабочие пространства

- Рабочие пространства для разных задач
- Группировка, поиск и восстановление вкладок
- Сохранение набора вкладок для последующего открытия
- Управление звуком отдельных вкладок

### Видео и скриншоты

- Режим «картинка в картинке» для поддерживаемых видео
- Автоматическое открытие видео в отдельном окне при переключении
  на другое приложение — с возможностью отключить эту функцию
- Сохранение прогресса просмотра поддерживаемых видео
- Скриншот экрана с помощью кнопки или сочетания Alt + N

### Приватность

- Блокировщик рекламы и трекеров с исключениями для сайтов
- «Чистый вход» — временная изолированная сессия для сайта
- Управление разрешениями сайтов
- Возможность очистить историю, кеш и данные сайтов
- Локальное хранение настроек и данных браузера

### Интерфейс

- Светлая и тёмная темы
- Настраиваемая страница новой вкладки
- Боковая панель с быстрым доступом к нужным разделам
- Плавные переходы и анимации
- Русский язык интерфейса

## Приватность

Chrone ориентирован на локальную работу. Настройки и данные браузера
хранятся на устройстве пользователя.

При посещении сайтов необходимые сетевые запросы отправляются
соответствующим сайтам, поисковым системам и другим сервисам.
Для некоторых функций, например обновления списков блокировщика,
может требоваться подключение к интернету.
